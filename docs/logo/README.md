# Logo

The ninge mark is the shell prompt `>` drawn as a half-open hinge, turned slightly so its two
panels show their screens. Black and white only.

| File | Use |
|---|---|
| `ninge-lockup.svg` · `ninge-lockup-white.svg` | Mark and wordmark side by side: the README header, banners |
| `ninge-lockup-stacked.svg` · `ninge-lockup-stacked-white.svg` | Mark above the wordmark: square spaces |
| `ninge-symbol.svg` · `ninge-symbol-white.svg` | The mark alone, 48 px and up |
| `ninge-symbol-small.svg` · `ninge-symbol-small-white.svg` | The flat mark for 16–40 px: favicons, tabs, small icons |
| `ninge-wordmark.svg` · `ninge-wordmark-white.svg` | The name alone, where the mark already appears nearby |

The plain files are black (`#000000`) for light backgrounds; the `-white` files are white
(`#FFFFFF`) for dark ones. The screens, the barrel line and the pin hole are cut out of the
shape, so the background shows through them in both.

## Rules

- **Clear space**: keep at least the height of the wordmark's `n` free on every side.
- **Size**: the turned mark needs 48 px; below that, use the flat `-small` mark. The lockup
  needs 120 px of width.
- **Colour**: black or white only, on a plain background with enough contrast. No other
  colours, gradients, shadows or outlines.
- **Shape**: do not rotate, stretch, mirror or redraw the mark, and do not change the wordmark's
  letters or spacing. The `n` gets no special treatment: the name is lowercase and no letter is
  emphasized.
- The wordmark is drawn as outlines, so no font is needed.
