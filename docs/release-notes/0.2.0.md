# ninge 0.2.0

The 2D release: both screens draw, with backgrounds, sprites, windows and blending. Install
with `cargo install ninge`, then run `ninge <rom>`.

## What works

- Both 2D engines draw their own screen: text, affine, extended and large-bitmap
  backgrounds, mosaic, and the extended palettes.
- Sprites: plain, affine and bitmap objects, with priorities and the per-line limit.
- Windows (WIN0, WIN1, the OBJ window and the outside region), blending, and the brightness
  fade.
- All nine video RAM banks, mapped for both engines and for the ARM7, with the status register.
- Display capture of engine A's screen into video RAM, and the main-memory display fed by DMA.
- The keypad registers read the host's buttons and the hinge.

## For hosts of `ninge-core`

This release changes the public API:

- `Machine::run_frame` now takes the frame's input. A host with no input passes
  `Input::default()`.
- New: `Input`, `Buttons` and `Touch`. `Input` is non-exhaustive: build it with `Input::new()`
  and the `with_buttons`, `with_touch` and `with_hinge_closed` methods.
- New: `Machine::audio`, the last frame's audio as interleaved stereo `i16` samples, whose
  length can change from frame to frame. It is still empty.
- The savestate format changed (version 32). Before 1.0 a state from another version is
  refused, so savestates from 0.1.0 do not load.

## Known limitations

- **The keyboard is not connected to the keypad yet.** The core reads input, but the terminal
  frontend passes none, so programs that wait for a key wait forever.
- **No touch screen.**
- **No cartridge reads.** Neither the cartridge protocol nor the file system on it is
  implemented, so programs that load files from it cannot run.
- **No 3D or sound.**
- **The real-time clock reads 0.** A program that shows the date shows the same fixed date.

These arrive in later releases; the roadmap is in `docs/PLAN.md`.
