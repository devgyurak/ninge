# ninge 0.1.0

The first release: a terminal-native emulator for a dual-screen handheld, written from scratch
in Rust. It runs in Ghostty and kitty and draws with the kitty graphics protocol.

Install with `cargo install ninge`, then run `ninge <rom>`.

## What works

- Both CPUs (ARMv5TE and ARMv4T) with a deterministic event scheduler.
- The two bus views, shared work RAM banking and the first video RAM bank as a background
  layer.
- Inter-processor communication, interrupts, timers, DMA, the HLE BIOS calls and direct boot
  (no firmware or BIOS dump is needed, and none is used).
- Text backgrounds on the top screen.
- A homebrew program built with the BlocksDS SDK can print to the console on the top screen.

## Known limitations

- **The bottom screen is blank.** The second 2D engine (engine B) is not implemented, so
  anything drawn there does not appear.
- **There is no input.** The keypad registers read "nothing pressed" at all times, and the
  keyboard is not connected to them yet. Programs that wait for a key wait forever.
- **No touch screen.**
- **No cartridge reads.** Neither the cartridge protocol nor the file system on it is
  implemented, so programs that load files from it cannot run.
- **No sprites, 3D or sound.**
- **The real-time clock reads 0.** A program that shows the date shows the same fixed date.

These arrive in later releases; the roadmap is in `docs/PLAN.md`.
